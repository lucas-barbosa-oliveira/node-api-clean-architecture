# Módulos copiados da plataforma

Cópia de `platform-infra/vault/modules` (root-pki, environment, service), para o ambiente local não depender do
acesso ao repositório da plataforma. **Não edite aqui**: altere na plataforma e sincronize com
`npm run vault:sync-modules` (lê `../platform-infra` ou `PLATFORM_INFRA_DIR`).
